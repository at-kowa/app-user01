# 物件状況ボード（架空データの試作）

物件ごとの受注・材料・工程・不良を、営業・業務・現場・工場長の4つの役割が同じ1画面で見るための試作です。生成AI研修の課題として作っています。

- **データはすべて架空です。** 実在の会社名・客先名・品番・図面・単価・金額・個人名は入れないでください
- このリポジトリは公開されています。鍵・パスワードは置きません
- 保守は作成した部署が行う前提です
- 要件は [docs/requirements.md](docs/requirements.md)（第2版）

## いまの段階

| 段階 | 内容 | 状態 |
|---|---|---|
| 1 GitHub | Next.js ＋ shadcn/ui で画面を作る。データはコードの中の架空20件、変更はそのPCのEdgeの中に保存。役割は画面上部で切り替える | 作成済み |
| 2 Supabase | データベースとログイン（役割別アカウント）につなぐ | これから |
| 3 Vercel | URLで使えるように公開する（無償版・試作のみ） | これから |

## できること（第1段階）

- 一覧：状態を5色で表示（遅れ＝赤／材料待ち＝黄／進行中＝青／引合＝白／出荷済み＝グレー）、納期注意・不良ありの目印、件数での絞り込み、担当班での絞り込み、納期の近い順
- 詳細：受注・材料・工程・不良・変更履歴。書ける欄は役割で決まる

| 役割 | 受注欄 | 材料欄 | 工程・不良欄 | 物件の追加・削除 |
|---|---|---|---|---|
| 営業 | 書く（受注区分を除く） | 見る | 見る | できる（引合で登録） |
| 業務 | 書く | 書く | 見る | できる（受注で登録） |
| 現場 | 見る | 見る | 書く | — |
| 工場長 | 見る | 見る | 見る | — |

第1段階の役割の切り替えは誤操作を防ぐためのもので、なりすましは防げません。第2段階でログインに置き換えます。

## PCで動かす

Node.js 22 以上が必要です。

```
npm install
npm run dev
```

Microsoft Edge で http://localhost:3000 を開きます。

社内のネットワークで `npm install` が証明書のエラーで止まるときは、PowerShell で `$env:NODE_OPTIONS='--use-system-ca'` を設定してから実行してください。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 入力した内容を最初に戻したい | 画面の足元の「初期データに戻す」を押す |
| 入力した内容が消えた | Edgeの閲覧データを削除すると消えます（第1段階はPCのEdgeの中だけに保存） |
| 「保存できません」と出る | InPrivate ウィンドウでは保存できないことがあります。通常のウィンドウで開いてください |

## 変更のしかた

作業ブランチで変更 → プルリクエスト → 人が中身を見てマージ。main への直接の push はしません。
